# When Correlation Isn't Enough: Using Causal Inference for Algorithm Bias Detection

Replication code for the paper *"When Correlation Isn't Enough: Using Causal
Inference for Algorithm Bias Detection"* (under review, anonymized).

The repository reproduces both studies in the paper: (1) a synthetic
loan-approval benchmark of six causal discovery algorithms against a planted
ground-truth discrimination edge, and (2) a causal analysis of the ProPublica
COMPAS recidivism dataset, including the adjusted direct-effect estimation,
bootstrap confidence intervals, and E-value sensitivity analysis.

## Requirements

- Python 3.11+ (tested on 3.12, Windows and Linux)
- Install dependencies:

```bash
pip install -r requirements.txt
```

Key packages: `causal-learn` (PC, FCI, GES, GRaSP, DirectLiNGAM with prior
knowledge), `lingam` (bootstrap estimators), `dowhy`, `statsmodels`,
`scikit-learn`, `pandas`, `numpy`, `matplotlib`.

## Data

The COMPAS analysis uses ProPublica's publicly available
`compas-scores-two-years.csv`. The loader downloads it on first run and
caches it under `data/`; no manual step is required. The synthetic
loan-approval datasets are generated by the code (fixed seeds), so no
external data is needed for Study 1.

## Reproducing the paper's results

```bash
# Study 1: synthetic benchmark (Table II, Figs. 1, 3)
python main_synthetic.py            # Generates the synthetic datasets

# Study 1: sensitivity grid, 480 runs (Fig. 2) — longest step
python main_sensitivity.py      # Runs the sensitivity analysis on the synthetic datasets

# Study 2: COMPAS pipeline (Tables III-IV, Figs. 4-5)
python main_compas.py

# Validation: bootstrap CIs (~3-5 min) and E-value (Fig. 6, Steps 4-5)
python bootstrap_ci.py
python evalue_check.py

# Robustness: unconstrained DirectLiNGAM (Section VI-B)
python run_dirlingam_compas.py
```

The synthetic data and all NumPy-based estimation are controlled by the data seeds in the scripts. GRaSP's permutation search is randomly initialized via Python's standard-library random module, which NumPy seeding does not control; run_grasp() therefore pins random.seed internally (default 42), and the sensitivity grid passes each repetition's seed through. With these seeds, every number in the paper — including Table II's GRaSP row — reproduces exactly from the commands above. 

## Notes on methodology choices encoded here

- **No standardization** is applied to the COMPAS frame; all Study 2 effects
  are in decile-score points per binary Race contrast (Section VI-B of the
  paper).
- **DirectLiNGAM prior knowledge** (Race/Sex/Age exogenous; Recidivism sink)
  is applied only in `main_compas.py`; `run_dirlingam_compas.py` provides the
  unconstrained comparison, and the bootstrap refits without background
  knowledge so that structural instability widens the intervals.
- **Bootstrap convention**: if a resample's recovered graph omits or reverses
  Race→Score, the coefficient is recorded as 0.0 rather than dropped.
